# 🌐 Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website built with **Next.js 15**, **React 19**, **TypeScript**, and **Tailwind CSS**. Designed with rich animations, dynamic 3D elements, and real-time activity tracking to showcase projects, skills, and competitive programming achievements.

---

## ✨ Features

- **⚡ Modern Tech Stack**: Built with Next.js 15 (App Router, Turbopack) & React 19 for optimal performance.
- **🎨 Sleek Dark & Light Themes**: Seamless theme toggling powered by `next-themes` and Tailwind CSS.
- **🚀 Project Showcase**: Editorial and flagship project sections highlighting AI systems, developer tools, and web applications.
- **📊 Coding Activity & Heatmap**: Real-time integration and visualization of coding stats and submission streaks.
- **✨ Dynamic Animations & 3D Visuals**: Smooth micro-interactions powered by Framer Motion and Three.js / React Three Fiber particle backgrounds.
- **📈 Visitor Counter**: Redis-backed dynamic visitor analytics powered by Upstash.
- **📄 Resume Preview**: Interactive resume modal with preview and direct download.
- **📱 Fully Responsive**: Thoughtfully crafted and polished for mobile, tablet, and desktop screens.

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js 18+ installed.

### Installation

1. Clone the repository:
   ```bash
   git clone git@github.com:Anirudh63/Anirudh63.github.io.git
   cd my-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables (optional for stats / Redis):
   Create a `.env.local` file in the root directory and add any required API keys.

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Scripts

- `npm run dev` - Start local development server with Turbopack
- `npm run build` - Build the application for production
- `npm run start` - Run the production build locally
- `npm run lint` - Run ESLint checks
- `npm run fetch:stats` - Fetch latest coding activity statistics
